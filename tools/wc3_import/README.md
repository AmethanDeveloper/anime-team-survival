# Перенос героев из карты Warcraft 3

Чем 32 героя попали из `Anime_Team_Survival_4_9v.w3x` в игру.

## Что где лежит

| Файл | Что делает |
|---|---|
| `heroes_map.json` | Всё, что вытащено из карты: характеристики, способности (имена, описания, перезарядки, дальность), личные сеты |
| `kits.py` | Какая способность карты каким типом стала в игре, русские названия и описания, особые параметры |
| `gen_heroes.py` | `heroes_map.json` + `kits.py` → `game/scripts/data_heroes.gd` (пересчёт чисел под масштаб игры) |
| `legacy_abilities.json` | Механика Акаме, Эсдес и Ичиго, сделанная вручную до переноса (названия берутся из карты) |
| `convert_model.py` | Модель `.mdx` → `model.glb` + `hero.json` для `game/heroes/<герой>/` |
| `mdx.py`, `mdx2gltf.py`, `pose.py`, `anims.py` | Чтение MDX, экспорт в glTF, поза стойки, выбор анимаций |
| `mpq.py`, `w3data.py`, `w3obj.py` | Чтение архива карты (нужна StormLib), таблиц SLK и `war3map.w3a` |

## Поменять баланс

Коэффициенты — в `gen_heroes.py`: `hero_stats()` (атрибуты, здоровье, урон, дальность) и `BUDGET` (сила способностей по слотам).
Типы, названия и особые числа способностей — в `kits.py`. Потом из корня проекта:

```
python tools/wc3_import/gen_heroes.py
```

Личные сеты всех героев — в `tools/gen_items.py` (таблицы `SETS` и `EX`), как и раньше:
`python tools/gen_items.py game/scripts/data_items.gd`.

## Сконвертировать ещё одну модель

```
pip install pillow numpy
python tools/wc3_import/convert_model.py путь/к/model.mdx game/heroes/<герой> путь/к/папке/с/текстурами
```

Скрипт кладёт `model.glb` и `hero.json` (рост модели в позе стойки, выбранные анимации Idle/Run/Attack/Cast/Death).
Части модели, которые в Warcraft видны только в отдельных анимациях (оружие, эффекты заклинаний), так и остаются:
в игре они появляются и пропадают вместе с анимацией.

## Как устроен перенос

- **Модели**: скелет, скиннинг, все анимации карты, текстуры BLP → PNG внутри GLB. Ауры и свечения, которым нужны
  стандартные текстуры Warcraft (их нет в карте), пропущены.
- **Размер**: рост считается по позе стойки, а соотношение размеров героев — по `modelScale` карты.
- **Иконки**: BTN/PAS-иконки способностей из карты; у [D] — иконка способности сета или самого сета.
- **Портреты**: рендер модели в Godot.
- **Озвучка**: mp3 из карты разложены по событиям по названию файла (`Spell Q` → q.mp3, `T`/`100`/`Ultimate` → d, остальное — select/attack).

## Способности «как в карте» (триггеры JASS → GDScript)

С этой версии способности героев работают так же, как в карте: код триггеров карты переведён из JASS
в GDScript и выполняется поверх игры.

| Что | Где |
|---|---|
| Переведённые триггеры героев (3 489 функций карты и Blizzard.j) | `game/scripts/w3/w3_map.gd` — не править руками |
| Константы common.j | `game/scripts/w3/w3_consts.gd` |
| Нативные функции WC3 поверх игры (юниты, группы, таймеры, эффекты, звуки) | `game/scripts/w3/w3_runtime.gd` |
| Базовые способности WC3 (Storm Bolt, Shockwave, Thunder Clap, Blizzard...), пассивки, баффы, уровни | `game/scripts/w3/w3_abil.gd` |
| Манекены и призванные юниты из триггеров | `game/scripts/w3/w3_unit.gd` |
| Модели эффектов: меши, частицы PRE2, ленты RIBB | `game/scripts/w3/w3_model.gd`, `w3_fx.gd` |
| Данные способностей, юнитов, звуков карты | `game/w3/w3_data.json` |
| Сконвертированные модели эффектов | `game/w3/fx/` (`index.json`: путь WC3 → файл) |
| Звуки триггеров | `game/w3/sounds/` |

Слоты героя: **Q W E R** — способности карты, **D** — врождённая способность, **T** — способность сета
(кат-ин при применении), у Широ и Эст книга заклинаний — кнопки над панелью (F, G, V).
Если в карте у героя нет способности для слота (Оригами), остаётся прежняя способность игры.

Пересборка (нужны карта и StormLib, как раньше):

```
python tools/wc3_import/jass/scope.py          # какие триггеры относятся к героям
python tools/wc3_import/jass/transpile.py out/ # JASS -> w3_map.gd, w3_consts.gd
python tools/wc3_import/jass/export_w3.py out/ # w3_data.json, звуки, список моделей
python tools/wc3_import/jass/fx_convert.py out/models_needed.json out/fx [папка с файлами Warcraft]
python tools/wc3_import/gen_heroes.py ...      # слоты способностей героев (w3kit.py)
```

### Стандартные эффекты Warcraft 3

113 моделей и большинство текстур эффектов карта берёт из самого Warcraft 3 (их нет в файле карты).
Пока они не извлечены, вместо них — мягкое свечение и запасные эффекты игры.
Запустите `ИЗВЛЕЧЬ_ЭФФЕКТЫ_WARCRAFT.bat` (список файлов — `extractor/war3_needed.txt`), появятся
`tools/wc3_import/war3_assets/war3_assets_NN.pak`. Распаковать: `python jass/unpak.py <папка .pak> <куда>`,
затем `fx_convert.py` с этой папкой третьим аргументом.

Эффекты и звуки лежат пакетами (`game/w3/w3_fx*.pak`, `w3_sounds_*.pak`, оглавления — `w3_fx.json` и
`w3_data.json`), игра читает их сама, импорт в редакторе не нужен. Собрать заново:
`python jass/pack_w3.py out/fx out/sounds out/w3_data.json game/w3/`. Текстуры BLP читает `blp.py`
(у Pillow пропадает прозрачность JPEG-текстур Warcraft).
